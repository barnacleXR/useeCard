# 数据导出、备份与恢复

设置页的“数据导出与备份”提供以下功能：

- **完整业务 JSON**：账户、卡片、所有状态的账单、月度检查、关联、用户偏好和图标。金额保留 `amountMinor` 与 `currency`；不包含密码哈希、会话、设备令牌、配对码或部署密钥。此文件是业务数据导出，不是恢复文件。
- **账单 CSV**：所有账单（包括已扣款、作废），同时包含币种、最小单位整数、规范十进制字符串；支持中文与带引号/换行的备注。可疑表格公式会添加单引号前缀。
- **完整备份**：使用 SQLite 在线备份 API 获取一致快照，包含 WAL 中的数据、图标、账号与数据库内的实例配置；封装文件包含格式版本、应用版本、结构版本、各表数量及 SHA-256 校验和。完整备份含账号认证资料，应私密保管。

## 保存位置与自动备份

默认放在数据库所在目录的 `backups/`，正式容器默认即 `/data/backups`，与数据库一起保存在数据卷中。可用部署变量 `BACKUP_DIR` 指定其他目录；需要确保目录可写且持久化。代码不会将部署环境中的秘密写入备份；封装只记录公开 BASE_URL 和业务时区作参考。

自动备份默认关闭。可选择每日/每周、日本时间、星期和 1–365 天保留期限。服务每 30 秒检查一次；当日在设定时刻之后启动会补做一次，同一天已成功的任务在重启后不会重复。服务关闭期间无法执行任务，也不补造每一个错过日期。失败记录显示在设置页，15 分钟后重试。

超期的手动/自动备份在自动备份成功后清理；恢复前快照单独保留。请定期下载备份并复制到另一台设备，同机备份不能防止磁盘损坏。

当前封装支持不超过 **64 MB 的数据库**（上传的 JSON 文件上限 90 MB），超出后请通过运维流程使用 SQLite 在线备份工具。备份不包含部署环境文件（`.env`，含 OIDC 客户端密钥与 Apprise 网关凭证）或反向代理配置，这些需要独立备份。

## 从备份恢复

1. 在当前实例登录管理员。如果是新服务器，先完成空库管理员初始化。
2. 进入设置，选择“从备份恢复”，上传 useeCard 完整备份，输入**当前管理员密码**并勾选替换确认。
3. 服务校验文件格式、校验和、结构版本、数据库结构、完整性、外键和表记录数量，并检查目录空间。当前只支持与运行服务结构版本一致的备份；其他版本需要使用对应版本程序恢复后再按升级流程迁移。
4. 服务进入维护状态（接口暂时返回 503），等待在途请求结束，先保存当前实例的完整快照。
5. 按外键依赖顺序在一个数据库事务中替换数据，发生错误会回滚。恢复前快照也可供后续手工恢复。
6. 成功后清除所有 Web 会话、设备会话、配对码、API Key 和 MCP 授权，关闭自动备份，保留备份中的实例 ID。用**备份中的管理员账号密码**重新登录并确认自动备份设置。部署地址与环境变量沿用当前服务器配置。

提醒按最新账单生成，恢复后自动重建；外部通知通道恢复后默认停用，需管理员核对后重新启用。iOS App 需要重新登录与同步以重新安排本地提醒，已安排的本地通知不会被远程取消。API Key 需重新创建，MCP 客户端需重新授权。
